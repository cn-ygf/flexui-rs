缺口，统一排成阶段计划。设计细节见 `09-资源管理设计.md`、`10-窗口标题栏与布局增强设计.md`。

## 需求编号速查

- **W1** Window width/height · **W2** Wails 式标题栏(mac 隐栏留交通灯 / win 系统栏) · **W3** 最大化最小化还原关闭 · **W4** 无边框 · **W5** 控件尺寸三态 · **W6** `<Window>` 作 XML Root · **W7** Include 子 XML · **W8** 代码动态 build + 按 name 取

## 阶段 1：资源与路径抽象（RM1-RM5）
**交付**
- 新 crate `flexui-resource`：`ResourceProvider` trait + `ResourceManager`。
- `DirProvider`（RM1）、`ZipProvider` 带密码（RM2）、`EmbeddedProvider` 内嵌（RM3）。
- `ImageSource` 扩展 `Res/Bytes`；两后端「从字节解码图片」+ 解码缓存。
- XML 经 `ResourceManager` 读取（RM5）；App 注入资源管理器（RM4）。
- （P1 可延）自定义字体从资源注册。

**出口**：同一份界面，资源既能从目录、也能从带密码 zip / 内嵌 zip 加载；XML 里
`src="img/x.png"` 三种来源都能显示。
**依赖**：无。 **决策**：D-RM1(zip crate)、D-RM2(解码缓存)。

## 阶段 2：布局盒模型重构（W5 + 缺口）
**交付**
- 控件尺寸三态 `Sizing::{Fixed,Content,Fill}`（W5），替换 `width/height: Option`。
- Flex **对齐**：justify-content + align-items（缺口）。
- **绝对定位**：显式 rect / x-y 摆放（缺口，兑现 C3/Box）。
- **四角独立圆角**（缺口，兑现 C3）：两后端自建圆角路径。
- 每子 margin、min/max 约束（缺口）。

**出口**：容器能按 start/center/end/space-between 排、交叉轴可对齐；子控件可固定/内容/撑开；
Box 可绝对定位；四角可不同圆角。
**依赖**：无（与阶段 1 并行）。 **决策**：D-W3(一次性改 Sizing API)。

## 阶段 3：窗口模型与标题栏（W1-W4 + 缺口）
**交付**
- `WindowConfig` 升级（W1：width/height/min/max/**resizable(禁止改大小)**/titlebar）。
- **两类窗口都支持**：有边框+系统栏（System）与 无边框自绘（HiddenKeepControls/None）。
- `TitlebarMode` 双平台实现：macOS 透明标题栏留交通灯 / Borderless；
  Windows 去系统栏(`WM_NCCALCSIZE`)+自绘按钮，**自绘按钮兼容系统 Snap**
  （`WM_NCHITTEST` 返回 `HTMAXBUTTON/HTMINBUTTON/HTCLOSE`，保留 Win11 Snap 浮层与贴靠）。
- `WindowHandle`：min/max/restore/close/toggle/start_drag/is_maximized（W3）。
- 禁止改大小：mac 去 Resizable styleMask；win 去 `WS_THICKFRAME/WS_MAXIMIZEBOX`。
- 自绘标题栏按钮 `on_click` **真正 wire** 到窗口控制（补缺口）；事件上下文注入 `WindowHandle`。

**出口**：有边框/无边框两类窗口双平台可用；禁止改大小生效；自绘按钮的最小/最大/关闭生效且
Win11 上能弹 Snap 浮层；无边框窗口可拖动缩放。
**依赖**：阶段 2 的 Sizing 便于标题栏布局（弱依赖）。 **决策**：D-W1、D-W2。

## 阶段 4：XML 增强（W6/W7/W8 + 缺口）
**交付**
- `<Window>` 作为 XML Root（W6）：`load_window(res, path, ctx) -> {config, root, bindings}`。
- `<Include src="...">` 子 XML 展开（W7），防环 + 深度限制。
- 代码动态 `build_fragment_str/res` + `find_mut_by_name`（W8）。
- （缺口）XML 样式复用/命名 style（`<Default>`）、XML 内事件绑定 `onclick="name"`。

**出口**：整窗 XML 从 `<Window>` 起；Include 拼装；运行时动态 build 片段并按 name 改控件。
**依赖**：阶段 1（资源读取）+ 阶段 3（Window 配置）。

## 阶段 5：P0 可用性补齐（缺口）—— ✅ 已完成
- ✅ **ScrollView** 滚动容器（含滚轮事件贯通，双平台 scrollWheel/WM_MOUSEWHEEL）。
- ✅ **Tab 焦点遍历**（KeyDown Tab → focus_next）。
- ✅ **Edit 光标编辑**：光标移动(左右/Home/End)、光标处插入、退格/Delete；平台无关键码
  `event::keys`，后端映射方向键(macOS 功能键字符 / Windows WM_KEYDOWN VK)。
- ✅ **Edit 剩余**：选区(Shift/鼠标拖拽/双击选词)、剪贴板(⌘/Ctrl C/X/V/A)、多行(仅显式换行、
  上下键、2D 命中)；**IME 组合输入**（macOS NSTextInputClient / Win WM_IME_* 内联组合串）。
- ✅ **脏区局部重绘**：分发器累积脏矩形 → 后端只失效该区域（setNeedsDisplayInRect/InvalidateRect）。
- ✅ 右键/双击、`ScaleChanged` 事件发出；I-beam 光标；Windows 鼠标 DPI 缩放/Enter 修复。

**已达**：P0 全部完成，Edit 达到可用文本框水准。
**依赖**：阶段 2（布局）。

## 阶段 6：P1 控件与体验（缺口）—— ✅ 已完成
- 控件：**✅ComboBox 下拉**、列表 ListView、**✅菜单/右键菜单**、**✅Tooltip**、**✅Slider**、**✅Progress**、**✅分隔条**。
  - ✅ Slider/Progress/Separator：自绘控件，`Base.value` 归一化 0~1，Slider 经指针转发拖动取值；
    XML 标签 `<progress>/<slider>/<separator>`（+orientation/thickness/value）。
  - ✅ **Overlay 浮层基础设施**：Dispatcher 持模态浮层栈（pop 栈顶路由，独立 overlay hover/pressed）
    + 被动 Tooltip；`paint_overlays`（place_overlay 下方/上翻/夹取）画在最上层不裁剪；选中经
    `activated→on_activate` 上报。ComboBox 经 activate 弹下拉；右键菜单经 `WindowCtx.open_menu`；
    Tooltip 复用闪烁定时器延时。XML `<combobox options=.. selected=..>`/`<item>` + `tooltip` 属性。
- ✅ 字体样式（粗体/斜体/下划线，Font 扩字段 + 两后端渲染）+ 单行**省略号**截断；多行文本已在阶段5完成。
- ✅ **动画/过渡基础** + 帧定时器：`anim` 引擎（Easing/AnimProp/补间），Dispatcher `animate/tick_anims`，
  两后端 ~60fps 帧定时器驱动，`WindowCtx.animate` 供 app 启动（value/scroll_y 属性）。
- ✅ **ListView**（裁剪在父内，点击选中，复用 scroll_at 滚动，XML `<listview>`）。
- ✅ **后台线程→主线程投递通道**：`MainProxy`(Clone+Send) + 邮箱，`WindowCtx.main_proxy()` 取句柄给
  工作线程 `send`；帧定时器排空交委托 `on_message`。

## 阶段 7：P2 收尾（缺口）
- 阴影/渐变/控件级透明度/变换；九宫格图片拉伸；非矩形命中。
- FFI 全量导出（逐控件构建/属性/回调）+ cbindgen 生成头文件。
- 多窗口；剪贴板/拖放/文件对话框/托盘。
- 无障碍(Accessibility)；benchmark；rustdoc 文档站 + 使用教程。

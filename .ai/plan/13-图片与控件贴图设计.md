# flexui-rs 图片系统 + 控件贴图设计

对应新需求：
- I1 支持常见图片格式；I2 PNG + **状态相关换色(tint)**；I3 SVG + 换色；
- I4 常见渲染方式(拉伸/平铺/九宫格/居中) + DPI；
- C-skin：radio/checkbox 等**用贴图替换各状态显示**（类 duilib）。

## 1. 现状与结论
- 常见位图(PNG/JPG/GIF/BMP/TIFF)**已支持**：后端用系统解码器加载
  （macOS `NSImage`、Windows GDI+）。→ I1、I2 的"加载"部分已具备。
- **新工作**：换色、SVG、渲染方式+DPI、控件贴图。

## 2. 换色 tint（关键，且可零依赖）
「基础黑图 + 布局时替换颜色」不需要我们逐像素解码，用系统的**颜色变换**即可，
保留系统解码器：
- **Windows**：`GdipCreateImageAttributes` + `GdipSetImageAttributesColorMatrix`
  （把 RGB 置为目标色、保留 alpha 形状）+ `GdipDrawImageRectRectI(..., imageattr, ...)`。
- **macOS**：CGContext `clip 到图片 alpha 掩码` 后用目标色填充；或 NSImage
  `lockFocus` + `SourceIn` 合成。
- **不同状态换不同色**：tint 作为**分状态样式字段**（见第 6 节），
  normal/hot/pushed/disabled/selected 各自可给不同 tint。→ 不用重复 P 图。

## 3. 渲染方式 ImageFit + DPI（I4）
```rust
pub enum ImageFit {
    Stretch,             // 整体拉伸填充（默认）
    Center,              // 居中原始尺寸
    Tile,                // 平铺
    NinePatch(Insets),   // 九宫格：四边不拉伸、中间拉伸
}
```
- 后端按 fit 绘制：Stretch=DrawImageRect；Center=按原尺寸居中；Tile=循环绘制；
  NinePatch=拆 9 块分别 DrawImageRectRect。
- **DPI**：绘制在物理像素上（窗口已按 DPI 缩放 world transform），图片按逻辑 rect
  绘制即自动到物理像素；九宫格边距按逻辑像素。

## 4. SVG（I3）——唯一需引入依赖
系统无 SVG 光栅化。方案：
- **纯 Rust `resvg`(usvg+tiny-skia)**：把 SVG 光栅化成 RGBA 位图（按目标物理尺寸，DPI 清晰），
  再走「绘制 RGBA 缓冲」的通用路径 + 第 2 节同款 tint。
- SVG 换色：先光栅化再套 tint 颜色变换（对黑色 SVG 生效，等同位图 tint）。
- **代价**：resvg 是"SVG 渲染库"，与 R2「不依赖第三方渲染库」有张力（但作用域仅限
  SVG→位图，UI 主渲染仍是 GDI+/CoreGraphics）。**需决策（见文末 Q1）**。
- 备选：暂缓 SVG，先做位图 tint + 渲染方式 + 控件贴图。

## 5. Canvas API 变更
- `draw_image` 增参数：tint(Option<Color>) + fit(ImageFit)。
- 新增 `draw_rgba(&mut self, rgba: &[u8], w, h, dest: Rect, tint, fit)`：
  供 SVG 光栅化结果 / 自解码结果绘制（后端从 RGBA 建位图再绘）。
- 图片来源 `ImageSource` 增 `Svg(Arc<[u8]>)`（延迟按尺寸光栅化）。

## 6. 分状态样式扩展 tint + fit + 控件贴图（C-skin）
### 6.1 图片层
StyleSpec 的 `bg_image/fg_image` 由裸 `ImageSource` 升级为 `ImageLayer`：
```rust
pub struct ImageLayer { pub source: ImageSource, pub tint: Option<Color>, pub fit: ImageFit }
```
### 6.2 selected 维度（贴图替换 checkbox/radio 各状态）
duilib 的 checkbox/radio 需要「勾选/未勾选 × 4 状态」的贴图。现状态槽是
`base(4)×focus(2)=8`，缺 selected。方案：**给 VisualState 加 `selected` 维度**，
StyleSet 改为稀疏 `HashMap<VisualState, StyleSpec>`，解析回退链：
`(base,focus,selected) → (base,false,selected) → (base,focus,false) → Normal`，再字段级兜底。
- CheckBox/Radio：**若生效样式带 bg_image/fg_image 则用贴图**，否则画默认指示器。
  这样 `normal-bgimage / selected-normal-bgimage / hot-bgimage ...` 即可完整换肤。

## 7. XML 属性
- 图片：`normal-bgimage="icon.png"`、`normal-bgtint="#3478F6"`、`normal-bgfit="ninepatch(6,6,6,6)"`。
- 控件贴图：`normal-bgimage` / `selected-normal-bgimage`（selected 前缀）/ `hot-fgimage` 等。
- SVG：`src="icon.svg"`（按扩展名或内容识别）。

## 8. 影响面
- `flexui-gfx`：ImageFit / ImageLayer / ImageSource::Svg / Canvas 增 tint+fit+draw_rgba。
- `flexui-core`：StyleSpec 用 ImageLayer；VisualState 加 selected；StyleSet 重构为 map；
  CheckBox/Radio 贴图优先。
- 后端：tint(ColorMatrix / CG mask)、fit(9 宫格/平铺)、draw_rgba(建位图)、（SVG 光栅化）。
- `flexui-xml`：新属性解析（tint/fit/selected 前缀/svg）。
- 依赖：SVG 若做，加 `resvg`（见 Q1）。

## 9. 建议实现顺序
1. 位图 **tint（换色）** + 分状态 tint（最高价值，零依赖）。
2. **ImageFit** 渲染方式 + DPI。
3. **控件贴图**（selected 维度 + checkbox/radio 贴图优先）。
4. **SVG**（视 Q1 决策）。

# flexui-rs 当前进度与下一阶段

> 本文是当前唯一进度基线，更新日期：2026-09-01。早期计划作为历史设计保留。

## 当前定位

- 版本仍为 `0.0.1`，定位是三平台桌面 UI 技术预览版。
- macOS / Windows / Linux 已共用控件树、布局、事件、主题、资源、XML 和本地化核心。
- XML 和纯 Rust 两种调用方式均为必须支持面。
- C ABI 已覆盖完整窗口生命周期、常用控件属性、动态 XML 子节点、剪贴板、文件对话框和主线程投递。

## 已完成

- M0–M11 全部完成；M12 中的控件、动画、系统集成、九宫格、多窗口和 FFI 主体已完成。
- 布局：Sizing 三态、Flex 伸缩/对齐、margin/padding、绝对定位、四角圆角、滚动。
- 控件：基础控件、Edit、ComboBox、ListView、VirtualList、菜单、Tooltip、Slider、Progress、Switch 和帧动画。
- 桌面能力：IME、剪贴板、文件对话框、多窗口/模态窗口、HiDPI、自绘标题栏、原生/自绘菜单。
- 工程：核心与 XML 单测、Clippy 零告警、rustdoc、benchmark、cbindgen 头文件防漂移。

## 已知边界

- Linux 托盘使用 StatusNotifierItem；GNOME 需要 AppIndicator 扩展，Wayland 下文件拖放由 XWayland 桥接。
- 控件变换当前为绕布局矩形原点的二维仿射变换；不改变布局占位，也不包含 3D 透视。
- Accessibility、TreeView 和系统通知不在当前收口范围。
- Apple String Catalog 的 substitution、device variation 和格式说明符仍未实现。

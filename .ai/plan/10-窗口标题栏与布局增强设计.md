# flexui-rs 窗口 / 标题栏 / 布局增强设计

对应新需求：
- W1：Window 有 width/height 属性。
- W2：Wails 式跨平台标题栏——macOS 隐藏标题栏但保留交通灯；Windows 用系统标准栏和按钮。
- W3：最大化/最小化/还原/关闭 的控制。
- W4：无边框（frameless）。
- W5：控件 width/height 支持「自动撑开 / 按子内容计算 / 固定大小」三态。
- W6：`<Window>` 作为窗口 XML 的 Root。
- W7：Include 子 XML（子 XML 的 Root 不是 `<Window>`）。
- W8：代码根据 XML 动态 build 子布局；动态创建的也能按 name 获取控件。

## 1. Window 模型（W1/W2/W3/W4）

把现有 `WindowConfig` 升级为完整 `WindowConfig` + 运行期 `Window` 句柄。

```rust
pub enum TitlebarMode {
    System,      // 原生标题栏 + 原生按钮（默认）
    HiddenKeepControls, // macOS：隐藏标题栏但留交通灯；Windows：无边框 + 自绘按钮
    None,        // 完全无边框（W4）
}

pub struct WindowConfig {
    pub title: String,
    pub width: f32,
    pub height: f32,
    pub min_size: Option<(f32, f32)>,
    pub max_size: Option<(f32, f32)>,
    pub resizable: bool,
    pub titlebar: TitlebarMode,
}

/// 运行期窗口控制句柄（暴露给控件回调/用户）。
pub trait WindowHandle {
    fn set_title(&self, s: &str);
    fn minimize(&self);
    fn maximize(&self);
    fn restore(&self);
    fn toggle_maximize(&self);
    fn close(&self);
    fn start_drag(&self);       // 自绘标题栏拖动窗口
    fn is_maximized(&self) -> bool;
}
```

### 1.1 macOS 实现要点
- `System`：默认。
- `HiddenKeepControls`：`styleMask |= FullSizeContentView`；`titlebarAppearsTransparent = true`；
  `titleVisibility = .hidden`；交通灯**保留**（不隐藏 `standardWindowButton`）。内容视图铺满，
  顶部留出交通灯区域由布局避让。窗口拖动用 `isMovableByWindowBackground=true` 或
  `performWindowDragWithEvent:`。
- `None`：`styleMask = Borderless`（交通灯也没了）；拖动/缩放自行处理。
- 控制：`NSWindow.miniaturize/zoom/close`；`isZoomed` 查询。

### 1.2 Windows 实现要点
- `System`：默认 `WS_OVERLAPPEDWINDOW`，系统标题栏 + 按钮。
- `HiddenKeepControls`：Windows 无「保留交通灯」概念——做法是**去掉系统标题栏**
  （`WM_NCCALCSIZE` 移除非客户区，或改 `WS_POPUP`），保留 `WS_THICKFRAME` 以保阴影/缩放，
  然后**自绘 min/max/close 按钮**（正是需求 C12：非 macOS 才渲染系统按钮）。
  拖动：`WM_NCHITTEST` 对标题栏区域返回 `HTCAPTION`；缩放边返回 `HTLEFT/HTTOP/...`。
- `None`：`WS_POPUP` 无边框无阴影，全部自绘/自处理。
- 控制：`ShowWindow(SW_MINIMIZE/SW_MAXIMIZE/SW_RESTORE)`、`SendMessage(WM_CLOSE)`；
  `IsZoomed` 查询。

### 1.3 标题栏按钮真正 wire（补之前缺口）
自绘的 min/max/close 按钮 `on_click` → 调 `WindowHandle` 对应方法。要把 WindowHandle
注入到控件回调可达的地方（如事件上下文 `EventCtx { window: &dyn WindowHandle }`），
需给 `on_event`/`on_click` 增加一个可拿到窗口句柄的上下文。

## 2. 控件尺寸三态（W5）

现状：`width/height: Option<f32>`（Some=固定，None=内容）+ `flex_grow`（撑开）。
重构为清晰的每轴 `Sizing`：

```rust
pub enum Sizing {
    Fixed(f32),   // 固定大小
    Content,      // 按子控件/内容计算（默认）
    Fill,         // 自动撑开填满父可用空间（等价 flex_grow=1）
}
pub struct Base { /* ... */ pub width: Sizing, pub height: Sizing }
```
- measure：`Content` 走现有内容度量；`Fixed` 用固定值；`Fill` 参与父容器剩余空间分配。
- 与 Flex 对齐（justify/align，见开发计划）配合，形成完整盒模型。
- XML：`width="120"`（Fixed）、`width="auto"`（Content）、`width="fill"` 或 `flex="1"`（Fill）。

## 3. `<Window>` 作为 XML Root（W6）

XML 顶层允许 `<Window ...>`，解析出窗口配置 + 内容子树：

```xml
<Window title="Demo" width="800" height="560" titlebar="hidden" resizable="true">
    <VBox> ... </VBox>
</Window>
```
- 新入口 `load_window(res, path, ctx) -> WindowDoc { config: WindowConfig, root: Node, bindings }`。
- `titlebar="system|hidden|none"` 映射 `TitlebarMode`；`width/height/resizable/min/max` 映射配置。
- 若顶层不是 `<Window>`（是普通容器），则视为「布局片段」（供 Include/动态 build，见下）。

## 4. Include 子 XML（W7）

`<Include src="逻辑路径"/>` 占位，加载时经 ResourceManager 读取子 XML 并就地展开：
```xml
<VBox>
    <Include src="parts/toolbar.xml"/>
    <Include src="parts/statusbar.xml"/>
</VBox>
```
- 子 XML 的 Root **不是** `<Window>`（是普通容器）。
- 解析器递归：遇到 `<Include>` → `load_fragment(src)` → 把其根节点插入当前位置。
- **防环**：维护 include 栈，重复路径报错；限制最大深度。
- 子 XML 内也可再 Include。

## 5. 代码动态 build 子布局 + 按 name 获取（W8）

```rust
// 从 XML 字符串/资源动态构建一个片段（Root 非 Window）
let frag: Node = flexui::build_fragment_str(xml, &ctx)?;      // 或 build_fragment_res(res, path, ctx)
// 插入到已有容器
some_container.push_node(frag);

// 动态创建的子树同样支持按 name 查找（已有 find_by_name，补可变版）
let id = flexui::find_by_name(&root, "okBtn");
if let Some(w) = flexui::find_mut_by_name(&mut root, "okBtn") {
    w.base_mut().text = "改了".into();
}
```
- 已有 `find_by_name`（只读）+ `visit_all_mut`；补 `find_mut_by_name`。
- 名字唯一性：建议同一棵树内 name 唯一；重复时 find 返回首个（文档说明）。
- 动态插入后需触发重新布局 + 重绘（现整树重排即可；有脏区后再优化）。

## 6. 对现有代码的影响面
- `flexui-core`：`Base.width/height` 改 `Sizing`；加 `find_mut_by_name`；`ImageSource` 扩展；
  事件上下文加窗口句柄。
- `flexui-xml`：`<Window>`/`<Include>` 解析；`width/height` 解析 auto/fill；经 ResourceManager 读取。
- `flexui-macos`/`flexui-windows`：`TitlebarMode` 实现、窗口控制、自绘按钮 wire、图片字节解码。
- `flexui`（facade）：`load_window`/`build_fragment` 入口、`ResourceManager` 注入。

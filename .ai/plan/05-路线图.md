# flexui-rs 路线图（里程碑）

按「先验证最高风险，再自底向上分层」推进。每个里程碑都要求双平台同步跑通。

> **进度（2026-08-07）**：M0–M8 全部完成；macOS + **Windows 双后端均已验证**。
> 工作区 8 个 crate 编译零警告、`cargo clippy` 零告警（host 与 windows 目标均 0）；
> 核心逻辑 19 个单元测试全绿；macOS/Windows GUI 示例可运行；
> C ABI 经真实 C 程序冒烟验证。已实现需求：**R1–R6 + C1–C12 全部覆盖**。
>
> **Windows 后端（R4）**：`flexui-windows` = Win32 窗口 + WndProc 消息循环 +
> GDI+ flat API 自绘（`windows-sys`）。在 macOS 上用 **zig 交叉编译 + wine 无头验证**：
> 离屏 GDI+ 渲染像素回读断言 `0xFF3478F6` 通过（WIN-GDIPLUS-OK）；FFI 入口 wine 运行通过；
> 窗口消息循环在 wine 存活不崩溃。一键脚本：`scripts/win-test.sh`。
>
> **GDI+ 双缓冲 + HiDPI（2026-08-07 增量）**：WM_PAINT 改为「画到 32bpp 离屏位图 → 整块
> blit 到窗口」，消除 resize 闪烁并让抗锯齿落在带 alpha 的表面上（`SmoothingModeAntiAlias`
> + 浮点圆角路径 + ClearType）；拦截 `WM_ERASEBKGND` 去背景擦除闪烁。
> DPI：`run()` 调 `SetProcessDpiAwarenessContext(PER_MONITOR_AWARE_V2)` + 每窗口
> `GetDpiForWindow` 求 scale，用 world transform 缩放（布局用逻辑像素、绘制到物理像素，高分屏清晰），
> 处理 `WM_DPICHANGED` 跨屏自适应。清单文件 `crates/flexui-windows/flexui.manifest`
> （PerMonitorV2/UTF-8/长路径；运行期已兜底声明 DPI 感知，最终 App 可按需嵌入）。
> 注：wine 软件 GDI+ 不光栅化路径抗锯齿，故 wine 下看仍有锯齿，真机 Windows 平滑。
>
> **crate 一览**：
> - `flexui-geometry` 几何/颜色 · `flexui-gfx` Canvas 抽象
> - `flexui-core` 状态机/样式/Flex 布局/控件/事件分发（19 测试）
> - `flexui-xml` 自写 XML 解析 + v-if + 平台谓词
> - `flexui-macos` AppKit 后端 · `flexui` 门面 · `flexui-ffi` C ABI
>
> **运行**：
> - 代码布局示例 `cargo run -p flexui-macos --example spike`
> - XML 布局示例 `cargo run -p flexui --example xml_demo`
> - C ABI 冒烟 见 `crates/flexui-ffi/examples/c_smoke.c`

## M0：可行性验证（spike）
- ✅ `spike-mac`（已完成 2026-08-07，本机验证）：NSWindow + 自定义 NSView(flipped)，
  drawRect 用 AppKit 原语（NSBezierPath/NSColor/NSString）自绘圆角按钮+文字，
  mouseDown 计数并 setNeedsDisplay 局部重绘。运行：
  `cargo run -p flexui-macos --example spike`。已验证开窗 + drawRect 触发（520x360）。
  代码分层：flexui-geometry / flexui-gfx(Canvas trait) / flexui-macos(CgCanvas+FlexView)。
- ✅ `spike-win`（已完成 2026-08-07）：`flexui-windows` Win32 窗口 + GDI+ 自绘，
  zig 交叉编译 + wine 无头验证（离屏像素回读 + FFI + 窗口消息循环）。
- **出口标准**：两平台均能开窗/自绘/收事件 —— ✅ 达成。

## M1：工程骨架 + 几何/绘图抽象
- 建 workspace：`flexui-geometry` / `flexui-gfx` / `flexui-core` / `flexui-macos` / `flexui-windows` / `flexui`。
- 定义 `Backend / PlatformWindow / Canvas` trait 与几何、颜色、字体类型。
- 两后端实现最小 `Canvas`：fill_rect / stroke_rect / draw_text / measure_text。
- **出口标准**：一份上层示例代码，双平台画出相同的矩形+文字。

## M2：事件系统 + 主循环
- 统一 `Event` 枚举；后端翻译原生事件；`Backend::run` 收口主循环。
- 命中测试 + 事件分发骨架。
- **出口标准**：点击窗口某区域，回调打印逻辑坐标，双平台一致。

## M3：控件模型 + 状态机 + 脏区重绘
- 控件 trait（layout/paint/on_event）、单子容器、控件树、脏区失效、局部重绘、`request_redraw`。
- **状态机**（Normal/Hot/Pushed/Disabled × focus）+ **StyleSet** 分状态样式解析与回退。
- **图片绘制**（背景/前景图，系统解码）；**HitPolicy** 事件穿透。
- Windows 双缓冲、macOS setNeedsDisplay 打通。
- **出口标准**：一个按钮，hover/press/focus/disabled 各态用不同色+图渲染，只重绘自身。

## M4：Flex 布局引擎 + 容器
- 盒模型（padding/margin/border）+ 主轴/交叉轴、方向、对齐、伸缩。
- `Box`（叠放）/ `VBox` / `HBox` 多子容器；rect 显式定位 vs Flex 优先级规则。
- **出口标准**：容器内多个控件按 Flex 规则自动排布，窗口缩放自适应。

## M5：基础 + 扩展控件库
- 基础：Label、Button、Image、CheckBox、Edit（基础版可延后）。
- 扩展：Radio + group 单选、TabBox、Radio↔TabBox 组成 tabbar。
- **出口标准**：用代码 API 拼出含 tabbar 的示例界面，双平台一致。

## M6：XML 布局 + v-if + 平台渲染
- `flexui-xml`：XML→控件树、属性→样式映射、分状态属性前缀（normal-/hot-/…/focus-）。
- `v-if` 加载期静态求值 + 平台谓词（`platform.macos/windows`）。
- **出口标准**：同一界面用 XML 描述可加载；非 macOS 才渲染自绘标题栏系统按钮。

## M7：HiDPI 打磨 + API 收敛
- backingScaleFactor / Per-Monitor DPI 全链路正确；公共 API 定稿（并保证可 C 化）。
- **出口标准**：高分屏清晰不糊；API 文档 + 示例齐全。

## M8：FFI 骨架（预留 R6）
- `flexui-ffi` cdylib：导出 app/window/widget 生命周期 + 点击回调最小集，cbindgen 生成头文件。
- **出口标准**：一个 C 示例程序 link 动态库，开窗+画按钮+响应点击。

---

## 优先级与并行建议
- **必须先做**：M0（验证风险）→ M1（打地基）。
- **可并行**：M0 的 mac / win 两个 spike；后续每个里程碑内 macOS 与 Windows 后端实现可并行推进。
- **可延后**：TextInput/IME、动画、主题、无障碍、Linux —— 均不在一期。

## 一期完成的判定
统一 API（代码 + XML 两种方式）能在 macOS + Windows 上，用 Flex 布局与 Box/VBox/HBox
拼出含 Label/Button/Image/Radio-tabbar 的界面；控件具备 4×2 状态与分状态样式；
支持事件穿透、v-if 与平台条件渲染（非 macOS 画系统按钮）；响应鼠标键盘、正确适配
HiDPI；且 FFI 骨架可被 C 调用。

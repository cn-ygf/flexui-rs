# 多语言与本地化

flexui 使用 SwiftUI Environment 风格的共享 `Localizer`。语言标签遵循 BCP 47，复数规则来自 CLDR；同一个 `Localizer` 的克隆共享目录、当前语言和修订号。

## 初始化

```rust
use flexui::{set_application_localizer, Localizer};

let localizer = Localizer::new("zh-Hans")?;
let resources = app_resources();
localizer.load_json_res(&resources, "i18n/zh-Hans.json")?;
localizer.load_json_res(&resources, "i18n/en.json")?;
set_application_localizer(localizer);
```

`Localizer::new` 的参数是开发语言。初始语言使用操作系统语言；读取或解析失败时采用开发语言。应用级环境会被主窗口、普通子窗口和模态对话框自动继承。

## JSON 目录

```json
{
  "locale": "en",
  "table": "Localizable",
  "strings": {
    "welcome": "Hello, {name}",
    "files": {
      "variable": "count",
      "plural": {
        "one": "{count} file",
        "other": "{count} files"
      }
    }
  }
}
```

`table` 可省略，默认是 `Localizable`。同一语言可以从多个 JSON 文件加载，条目会按 table 合并，后加载的同名条目覆盖旧值。

## Apple String Catalog

可以用 `load_xcstrings_str` 或 `load_xcstrings_res` 加载 `.xcstrings`。当前支持：

- `sourceLanguage`
- `localizations.*.stringUnit.value`
- `localizations.*.variations.plural`

复数参数名目前固定为 `count`。Apple 的 substitution、device variation 和格式说明符尚未实现。

## XML

目录中存在的普通属性值会自动作为 key；不存在时按字面量显示，因此旧布局无需迁移即可继续使用。

```xml
<Window title="window.settings.title" title-args="name=UU">
  <VBox>
    <Label text="settings.title"/>
    <Label text="loc:required.key"/>
    <Label text-verbatim="Never localized"/>
    <Edit placeholder="phone.hint" placeholder-args="country=CN"/>
    <Button tooltip="button.close"/>
    <ComboBox options="locale.system,locale.zh_hans,locale.en"/>
    <ListView>
      <item text="item.first"/>
      <item text-verbatim="Literal item"/>
    </ListView>
  </VBox>
</Window>
```

支持本地化的属性：

- `title`、`text`、`placeholder`、`tooltip`
- `options`、`items` 和 `<item text>`
- 对应的 `*-args="name=value,count=3"`
- `loc:key` 强制建立绑定，即使 key 当前不存在
- `title-verbatim`、`text-verbatim`、`placeholder-verbatim`、`tooltip-verbatim` 和 `<item text-verbatim>` 强制使用字面量

切换语言会更新窗口标题、文本、提示文本、占位文本及列表项，并触发布局和重绘。Edit 的实际输入内容、焦点、选区、列表选中索引和滚动位置会保留。

## 代码 API

```rust
use flexui::LocalizedStringResource;

let message = LocalizedStringResource::new("files")
    .arg("count", 3);

ctx.set_locale("en-US")?;
ctx.set_system_locale()?;
ctx.set_localized_text("status", message);
```

`ctx.set_text` 表示业务代码接管当前文本，因此会解除原有 `Text` 本地化绑定。需要让动态文案在以后继续响应语言切换时，应使用 `ctx.set_localized_text`。

## 回退规则

语言按最具体到最宽泛逐级回退，再回退到开发语言。例如：

```text
zh-Hant-TW -> zh-Hant -> zh -> development locale
en-US -> en -> development locale
```

找不到 key 时优先使用 `LocalizedStringResource::default_value`，否则直接显示 key。参数使用 `{name}`，`{{` 和 `}}` 分别表示字面量花括号。

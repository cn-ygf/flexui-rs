# flexui-rs 风险、难点与待确认决策

## 1. 待用户确认的决策（会影响架构，优先拍板）

| # | 决策点 | 选项 | 建议 | 影响 |
| - | ------ | ---- | ---- | ---- |
| D1 | 「第三方库」边界是否包含 OS API 绑定 crate（`objc2`/`windows-rs`） | 允许 / 禁止(全手写 extern) | **✅ 已确认：允许** | 已拍板，可放心用绑定层 |
| D2 | macOS 绘图 API | Core Graphics(Quartz) / 其他 | **Core Graphics** | 决定 Canvas 后端实现 |
| D3 | 渲染模型 | 保留模式 / 即时模式 | **保留模式** | 决定控件树与脏区机制 |
| D4 | 布局模型 | Flex / 手动绝对定位 / 约束 | **Flex**（合库名） | 决定布局引擎 |
| D5 | 线程模型 | 单线程 / 多线程异步 | **一期单线程** | 决定事件循环复杂度 |
| D6 | 工程形态 | workspace 多 crate / 单 crate 模块 | **workspace** | 决定初始脚手架 |

> D1 是最关键的一条。若用户坚持「一个第三方 crate 都不引入」，需据此重估工作量与排期。

## 2. 技术难点（按风险从高到低）

1. **运行时子类化 NSView（高）**：覆写 `drawRect:`/事件方法、正确处理 objc 内存与
   消息转发，是 macOS 后端最易出错处。缓解：用 `objc2` 的 `declare_class!` 宏，先做最小
   可跑 demo 验证。
2. **GDI+ flat API 封装繁琐（中高）**：句柄多、错误码风格、双缓冲防闪烁。缓解：统一
   RAII wrapper，先打通「窗口里画一个矩形 + 一行字」。
3. **双平台文本一致性（高）**：字体、度量、抗锯齿、换行策略差异大，难做到像素级一致。
   缓解：统一度量口径，接受「视觉接近」而非「逐像素相同」；文本单独立测。
4. **HiDPI / 多屏 DPk（中）**：Windows 运行时 DPI 变化、macOS 多屏 scale。缓解：坐标
   全走逻辑像素，缩放集中在后端绘制层。
5. **事件循环所有权与线程约束（中）**：两平台主循环形态不同、UI 必须主线程。缓解：
   `Backend::run` 收口，禁止上层直接碰原生循环。
6. **IME / 文本输入（高，故一期排除）**：原生输入法组合极复杂。缓解：一期 TextInput
   只做基础 ASCII/直接输入，IME 延后。
7. **FFI 边界安全（中）**：panic 穿越、所有权、字符串编码。缓解：`catch_unwind` +
   成对 create/destroy + cbindgen。
8. **无第三方渲染库导致的长尾工作量（中）**：无障碍、动画、富文本等都得自己写。
   缓解：严格控制一期范围（见 `00-需求分析.md` 第 3 节）。
9. **XML 解析 + v-if 求值（中）**：属性→控件属性映射、表达式求值、平台谓词。缓解：
   属性映射用注册表/宏收敛；v-if 一期只做**加载期静态求值**，不做响应式。
10. **图片加载/绘制双平台一致（中）**：解码、缩放、九宫格。缓解：一期只做普通绘制，
    用系统解码（NSImage / GDI+ Bitmap），九宫格延后。
11. **分状态样式的组合爆炸与回退规则（中）**：8 槽 × 8 字段，若无清晰回退会难维护。
    缓解：字段全 `Option`，统一「状态优先级 + 字段级回退到 Normal」一处实现。
12. **rect 显式定位 vs Flex 自动布局的优先级冲突（中）**：缓解：明确规则——Box 用显式 rect，
    V/HBox 走 Flex（rect 仅作尺寸提示），写进布局引擎文档。

## 3. 对约束 R2 的解读与建议

「不依赖第三方渲染库、窗口管理器」应理解为：**不引入 winit/SDL/GLFW/skia/cairo/wgpu
等功能性框架**；而 `objc2`/`windows-rs` 这类**仅声明 OS API 的绑定层**不属此列。
建议在项目 README/约定里**白纸黑字写明这条边界**，避免后续反复。

## 4. 验证优先（降低最大风险）

在铺开架构前，建议先做两个**最小验证 spike**（各自独立、可并行）：
- **spike-mac**：`NSWindow` + 自定义 `NSView`，`drawRect` 里用 CGContext 画一个
  圆角矩形 + 一行文字，响应一次 `mouseDown`。
- **spike-win**：`CreateWindowExW` + `WndProc`，`WM_PAINT` 用 GDI+ 双缓冲画同样内容，
  响应一次 `WM_LBUTTONDOWN`。

两个 spike 跑通，说明「自绘 + 事件 + 无第三方框架」路线可行，再进入正式分层实现。

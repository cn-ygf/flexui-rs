# flexui-rs 缺口与待办（诚实盘点）

> **历史盘点**：本文反映 2026-08-07 的状态，其中大量缺口已完成。当前状态以 `14-当前进度与下一阶段.md` 为准。

盘点日期 2026-08-07。基于代码实际状态，非计划意图。分「已做」「部分/有局限」「未做」。

## 一、已做且验证（不再赘述）
双平台窗口/事件循环、自绘、Canvas 抽象、状态机(4×2)+分状态样式、Flex 主轴+flex_grow、
Box/VBox/HBox、命中穿透、Label/Button/Image/CheckBox/Radio+group/TabBox/Edit(基础)、
代码+XML 双布局、v-if+平台谓词、tabbar、图片绘制、GDI+ 双缓冲、HiDPI、C ABI 骨架。

## 二、部分实现 / 有局限（名实有差距的地方）

| 区域 | 现状 | 差距 |
| ---- | ---- | ---- |
| **局部重绘** | 每次事件整窗失效 + 整树重新布局重绘 | plan 里的「脏区/局部重绘」**未实现**，实为整窗重画（小 UI 够用，大 UI 不优化） |
| **Flex 对齐** | 主轴恒从头排、交叉轴恒拉伸 | 无 justify-content / align-items / flex-wrap / min-max / 每子 margin |
| **绝对定位** | Box = 叠放填充 | C3「rect 参数」、Box 按 x/y 摆放**未实现**（StyleSpec 无 rect 字段） |
| **圆角** | 两后端只用 `Corners.tl` 一个半径 | 四角独立圆角**未落地**（类型在、渲染未用） |
| **Edit** | 末尾追加 + 退格 | 无光标移动/选区/剪贴板/多行/滚动/**IME** |
| **文本** | 单行、系统度量 | 无换行/省略号；双平台度量口径不同(CoreText vs GDI+)，同 UI 尺寸可能略差；无粗体/斜体/下划线 |
| **尺寸** | width/height 仅像素固定值 | 无百分比/约束/自适应上下限 |
| **标题栏系统按钮** | XML 里能画 min/max/close | 点击只回调，**未 wire 到真正关窗/最小化/最大化** |
| **FFI** | version/load_check/按 name 点击/run_xml | 无逐控件构建、属性 setter/getter、逐控件回调；头文件手写非 cbindgen |
| **XML** | 内联样式 + v-if 静态 | 无样式复用/模板(`<Default>`)、无 XML 内事件绑定、无响应式、文本节点忽略 |

## 三、完全未做

### 事件
- **滚轮** MouseWheel：枚举有，后端不产生、分发器不处理。
- **右键/中键/双击**：只处理左键。
- 键盘：无方向键/Enter/Tab；无 **Tab 焦点遍历**；键码未统一（平台原始码透传）。
- `ScaleChanged` 定义了但从不发出；无精确 mouse enter/leave（hover 靠 move 推断）。

### 控件（缺口最大）
- **滚动容器 ScrollView**（内容超出不可滚）——真实 UI 的重大缺口。
- 下拉框/组合框、列表 ListView、菜单/**右键菜单**、Tooltip、Slider、Progress、分隔条、TreeView。

### 渲染
- 阴影 / 渐变 / 控件级透明度 / 变换(旋转缩放)。
- 九宫格图片拉伸。
- 非矩形命中（圆角区域仍按矩形命中）。

### 系统集成
- 剪贴板、拖放、文件对话框、系统托盘、通知。
- 窗口最小/最大尺寸、图标、菜单栏；**多窗口**（run 只开一个窗口且阻塞）。

### 线程 / 时间
- 单线程；无「后台线程→主线程」投递通道（plan 提过预留，未实现）。
- 无定时器 / **动画 / 过渡**系统。

### 国际化 / 无障碍
- **IME 组合输入**（中文/日文输入不可用）。
- BiDi / 复杂脚本 shaping。
- 无障碍(Accessibility) / 屏幕阅读器（一期明确排除）。

### 工程
- 后端(macos/windows)无单元测试（靠示例验证）；核心逻辑 19 个测试。
- 无 rustdoc 文档站 / README / 使用教程。
- 无 benchmark。

## 四、建议优先级（若继续）

**P0（挡住真实可用）**
1. 滚动容器 ScrollView。
2. Flex 对齐（justify-content / align-items）+ 绝对定位 rect。
3. Edit 完善（光标移动/选区）+ **IME**。
4. 脏区局部重绘（性能）。
5. 标题栏系统按钮真正 wire 到窗口操作。

**P1**
6. 更多控件（下拉/列表/菜单/Slider/Progress）。
7. 四角独立圆角、多行文本+省略号。
8. 右键/滚轮/Tab 焦点遍历。
9. 后台→主线程投递 + 定时器。
10. XML 样式复用/模板 + 事件绑定。

**P2**
11. 动画/过渡、阴影/渐变、九宫格。
12. FFI 全量导出 + cbindgen。
13. 多窗口、剪贴板/拖放。
14. 无障碍、benchmark、文档站。
